## トップページ

画像: [top](image/top.png)

URL: `/`

- ルームを新規作成します（ルーム名を入力）。
- 作成後、ルーム詳細（登録）ページへリダイレクトします（`query_key` 付き）。

## セキュリティページ

画像: [security](image/security.png)

URL: `/rooms/{room}`（`query_key` が無い / 不一致のとき）

- アクセスキー（`query_key`）不一致時に表示される確認ページです。
- 正しい値を入力すると、対象ルームに入室できます（ルーム詳細へ遷移）。

## 登録ページ

画像: [room](image/room.png)

URL: `/rooms/{room}?query_key=...`

- URL ごとにルームが生成され、共有したい人へ URL を渡して参加してもらいます（`query_key` 付き URL を共有）。
- メンバーを追加できます。
- 支出項目を追加できます（誰が、誰の分を、いくら支払ったか）。
- 支出登録時に、現在地の位置情報（緯度/経度）を保存できます。
- 画面内のリンクから、メンバー編集 / 品目編集ページへ遷移できます。

## メンバー一覧（編集）ページ

画像: [members](image/members.png)

URL: `/rooms/{room}/members?query_key=...`

- 登録済みメンバーの一覧表示と、名前の更新ができます。
- ルーム詳細ページから遷移します。

## 品目一覧（編集）ページ

画像: [items](image/items.png)

URL: `/rooms/{room}/items?query_key=...`

- 登録済み品目の一覧表示と、以下の更新ができます。
  - 品目名
  - 対象者（誰の分か）
  - 位置情報（緯度/経度）
- 金額・支払者は固定です（編集ページでは変更できません）。
- 品目の削除ができます。
- ルーム詳細ページから遷移します。

## 清算ページ

画像: [settlement](image/settlement.png)

URL: `/rooms/{room}/settlement?query_key=...`

- ルームの合計金額や、各メンバーの支払い状況を表示します。
- 清算の結果（誰が誰にいくら払うか）や、おつり計算、訪れた場所を確認できます。

### 支払い清算

- 清算アルゴリズムに基づいて、支払い調整結果を表示します。
- 誰が誰にいくら支払うかを確認できます。

### おつり計算

画像: [calculator](image/calculator.png)

- 最終的な支払い額を表示し、支払い完了を判定します。
- 完了したメンバーは「清算完了」欄に表示されます。

### 訪れた場所

画像: [visited](image/visited.png)

- 入力した品目の位置情報を一覧表示します。
- 入力順にルートを生成し、Google Maps で軌跡を確認できます。
