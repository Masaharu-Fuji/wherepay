# 旅行・グループ活動 費用管理アプリ

## アプリ概要

このアプリケーションは、**旅行や一日イベントなどのグループ活動における「お金の管理」と「清算」を、位置情報と紐づけて行える Web アプリ**です。

「どこで・誰が・いくら払ったのか」をその場で簡単に記録し、活動の最後に自動で割り勘を計算してくれるため、現地でのお会計から最終清算までをスムーズにします。

バックエンドには **Laravel**、フロントエンドのビルドには **Vite** を採用

---

## ユーザ向けの説明

- **その場でサッと支出登録**
  - お店や観光地などの「現在地」と紐づけて支出を記録できます。
  - 項目（例: 交通費・食事・観光・宿泊 など）と金額、支払ったメンバーを選ぶだけのシンプルな操作です。

- **位置情報と一緒に思い出を可視化**
  - どの場所でいくら使ったのか、地図やリストで振り返ることができます。
  - 「この日はどこで何をしたか」を、支出と一緒に確認できるため、旅のログとしても活用できます。

- **最後はワンタップで割り勘結果を表示**
  - 全員分の支出をもとに、「誰が誰にいくら支払えば公平か」を自動計算します。
  - 複雑な計算やメモは不要で、画面を見ながらそのまま清算できます。

- **スマホからすぐ使える Web アプリ**
  - ブラウザからアクセスするだけで利用でき、アプリのインストールは不要です。
  - スマートフォン・タブレット・PC など、複数デバイスで利用できます。

---

## 技術スタック

- **フレームワーク**
  - バックエンド: Laravel (PHP)
  - テンプレート: Twig
- **フロントエンド**
  - ビルドツール: Vite
  - 言語: JavaScript
  - スタイル: TailwindCss

`backend/` ディレクトリ配下に Laravel プロジェクトを配置し、Vite によるアセットビルドを組み合わせる構成です。

---

## 想定ユースケース

- 友人グループでの旅行・合宿の費用管理と割り勘
- 社員旅行やチームイベントでの立替精算の簡略化
- 大学ゼミ・サークル活動の現地支出管理
- イベント運営における、当日発生する小口経費の記録とレポート作成

## 現在の実装機能

### 1) ルーム作成画面（`/`）

- グループ名入力によるルーム作成
- 入力バリデーションエラー表示

### 2) アクセスキー入力画面（`/rooms/{room}` ※キー不一致時）

- `query_key` を入力してルームへ入室
- ルーム選択（作成）画面へ戻る

### 3) ルーム詳細画面（`/rooms/{room}?query_key=...`）

- メンバー追加・メンバー一覧表示（人数表示つき）
- 品目追加（品目名、金額、支払者、対象者[複数選択]、位置情報取得）
- 品目一覧表示（品目名、支払者、対象者、金額、作成日時、1人あたり金額、位置情報ありバッジ）
- 品目削除
- ルームURL表示・コピー
- 品目一覧CSV出力
- 清算結果画面への遷移（条件: メンバー・品目が存在）
- 支払いランキング表示（開閉式）

### 4) 清算結果画面（`/rooms/{room}/settlement?query_key=...`）

- 清算サマリー表示（合計金額・メンバー別負担）
- 支払い計算結果表示（誰が誰にいくら払うか）
- おつり計算（メンバー別所持金入力、不足/おつり表示、清算完了判定）
- 清算完了メンバー一覧表示
- 全員完了時の「清算完了」表示
- 訪れた場所一覧表示（各地点の地図リンク、全体経路表示リンク）
- 清算結果CSV出力
- 清算を確定して保存（`Settlement` レコード作成）
- ルーム詳細へ戻る
